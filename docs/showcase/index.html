Tensors the compiler understands

Nova is a statically typed language for machine learning, with Python-style layout and tensors, autograd and GPU-cluster training built in. NovaComp is the cloud IDE around it: write in the browser, run in a sandbox, train on A100s.

Roadmap

        
Toward the compilers ML hardware is built on

        
SSA IRs in MLIR, lowering through several levels, code generation for a hardware target, and scheduling driven by its memory hierarchy. Each step comes with its design decisions written down.

      

      

      

    

  


  
  

    

      

        
Get started

        
Build it, test it, train XOR

        
You need make, a C++17 compiler (g++ or clang++) and Node.js 22.12+.

      

      

        

          
terminal


git clone https://github.com/parhitmtech/Nova.git && cd Nova
make -C compiler                      # builds compiler/build/nova
make -C compiler test                 # the golden language tests

export NOVA_HOME=$PWD/compiler        # where `orbit` finds the stdlib
compiler/build/nova examples/xor.nova # trains a 2-layer network on XOR
